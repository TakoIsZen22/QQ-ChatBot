# QQ ChatBot 新手使用教程

当前发行：**1.00.01 · 自有 API 版**。仅支持自有 OpenAI 兼容 API；没有 Magpie 接入入口。

适用 1.00.01（仅自有 API）与 1.00.02（自有 API + 可选 Magpie）。先按 [版本选择](EDITIONS.md) 下载对应 ZIP。两版沿用此前本机验证的 QQ 宿主；Windows 包支持在向导下载固定官方组件并手动扫码，每个新账号与新机器仍需自己验收。

## 安装与打开

在 GitHub Releases 的 Assets 中选择与版本一致的 Windows x64 ZIP，完整解压到独立可写目录，双击 `QQ ChatBot.exe`。Source code ZIP 是源码，需按 README 安装 Python 环境。Windows 10/11 x64 需要 WebView2、.NET Framework 与 VC/UCRT。不要只复制 EXE，也不要在压缩包内运行。

源码用户双击 tools/install.bat、tools/install-desktop.bat，另按 WINDOWS_BUILD.md 编译自写 QQ 宿主，再打开根目录 QQ ChatBot.vbs。窗口 X 默认收进托盘，真正退出用托盘菜单或 Ctrl Q。

## 接入模型并聊天

1. 首次向导可以稍后设置 QQ。打开“设置 → 模型与 API 接入”。
2. 1.00.01 填自己的 OpenAI 兼容 API Base URL；1.00.02 可选同样的自有 API，或已有 Magpie（http://127.0.0.1:3425/v1）。
3. 自有 API 的密钥由你在 Windows 用户环境变量中设置；这里只填写环境变量名称，不能填写密钥。1.00.02 使用 Magpie 时，上游凭据仍在 Magpie 配置。修改环境变量后彻底退出再打开。
4. 点击检查连接，选择实际模型 ID，保存并重启聊天。检查模型清单不代表推理已验证。
5. 手动点“只回复”，在本机对话页发消息。识图需要填支持图片的辅助模型 ID，可上传、粘贴或拖入图片。

完整接入：[自有 API 教程](MODEL_API.md)。1.00.02 另含 [Magpie 教程](EDITIONS.md)。

## 定制与记忆

“专属人设”可编辑、导入和预览 soul.md，也可更换昵称、头像与程序图标；保存后应用。私人文件与历史在 data 内，不进入公开包。“长期记忆”“她的日记”“约定与学习”可查看和手工管理；日记每天不超过三条。表情理解页可上传图片并确认你赋予它的含义。

“工作转交”可绑定通用 CLI 或桌面 Agent，默认关闭。只有你明确确认的当前文字任务会转交，不自动携带聊天和人设。见 [工作教程](AGENT_WORK.md)。

## QQ 与群监听现状

“程序设置 → 首次使用 / QQ 接入”保存两个不同账号与模型，点击准备组件，然后用机器人 QQ 扫码、手机确认。过期可刷新，错误或掉线可停止接入后重启。确认在线后先发消息验证接收，再由你手动开启“只回复”并发一条新消息验收回复。不会借用或修改日常 QQ。群监听可多窗显示，新增或重新启用群后需手动停止并启动 QQ 更新原生白名单；群只监听不回复。

QQ 操作与恢复步骤：[QQ 接入](QQ_SETUP.md)、[原生桥接](NATIVE_QQ.md)。账号、登录验证只能由使用者完成，不向维护者提供密码或凭据。

## 程序与数据维护

“程序设置”可设置开机自启、托盘、主题和字号。自启尊重人工停止意图及暂停，QQ 仍需手动扫码接入。顶部“全部暂停”停止输出；“只回复”由你手动开启，群静默不解除。

备份：程序设置 → 创建快照 → 验证。恢复：选择快照 → 验证 → 恢复 → 核对记忆、日记和附件；恢复保持停止及暂停，确认后重新打开。不要只备份 memory 文件，须保留完整 data。API 环境变量和 QQ 登录态需另行保管。

故障时先在程序内运行只读巡检与查看运行记录。不要批量关闭 Python 或 QQ，不要删除日志、去重和限流记录。具体命令见 HANDOFF.md。软件包不包含你的账号、聊天、私人 soul 或登录态。
