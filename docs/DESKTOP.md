# 桌面程序使用说明

日常双击桌面或开始菜单「QQ ChatBot」。不需要终端，重复打开只唤回已有窗口。侧栏「设置」管理模型与陪伴；「程序设置」管理Windows和程序本身。

可在「程序设置 → 本机账号与锁定」设置账号密码，设置和登录时可选记住密码、自动登录。密码用 Windows 当前用户加密保存，手动锁定或默认收进托盘会关闭自动登录；锁定不会停止后台聊天，登录页仍有全部暂停。程序设置可忘记保存的密码。修改密码、会话、备份和忘记密码恢复步骤见 [本机登录](LOCAL_LOGIN.md)。启用后冷启动服务需先登录，再在总览启动；未启用时保持原来的启动行为。

侧栏「群聊监听」支持群标签和多窗并排、群设置、公开人设、上下文重置、群静音及未回复原因。默认仅监听；逐群明确开启后可 @回复或每条文字回复，仍须 QQ 在线、配置已同步且允许群输出。更新后首次手动重启聊天服务和 QQ，随后群设置即时同步。真实群收发待验收，完整步骤见 [群聊教程](GROUP_MONITOR.md)。

程序名是 QQ ChatBot；默认伴侣昵称「大肥鱼」仍可在「专属人设」中独立修改。旧安装更新后会迁移本安装的旧快捷方式和已启用的启动项，保留记忆、人设与图标。

## 启动、关闭与退出

- 「开机自启」登记到**当前用户**的Windows登录启动项，不需要管理员权限，也不是登录前的系统服务。自启默认收进托盘；双击托盘图标或桌面快捷方式打开。
- 「打开程序时启动服务」控制聊天核心；QQ 由首次向导手动扫码，已有自有宿主保留。所选模型服务由用户管理；Magpie模式可在Magpie中设置自启，自定义模式直接使用配置的API，不要求运行Magpie。
- 默认点窗口X或最小化会收进系统托盘，右键托盘可打开、暂停、只回复、启停服务或退出。托盘图标有时位于Windows任务栏的折叠区域。
- 「仅退出界面，后台继续」结束窗口、托盘和恢复守护，聊天与QQ继续；「退出并停止全部」先暂停聊天，再停止本项目核心服务，不影响个人QQ或Magpie。
- 托盘不可用时不会把窗口藏起来；Windows关机/注销不被关闭到托盘的行为阻挡。窗口位置、大小、最大化状态会保存，越界位置会忽略。

## 后台恢复与暂停

打开「后台异常自动恢复」后，程序驻留期间会检查聊天核心，意外退出时限次拉起（默认每10秒检查、5分钟内最多3次）。超过上限会在程序设置中显示，需排障后手动启动。QQ宿主不会被自动拉起或登录，掉线未恢复时由用户停止并扫码。电脑休眠时程序不执行，唤醒后继续检查与重连。

顶部或托盘「全部暂停」立即取消后续发送；恢复守护**不会解除暂停**。手动「停止全部」、维护脚本stop.bat或本机停止API会保存停止意图，守护不再拉起。显式启动/重新打开程序（启用自动启动服务时）才重新启动；持久化暂停仍保留。

## 外观与快捷键

「设置 → 模型与 API 接入」提供程序内的「Magpie 接入教程（可选）」和「自有 API 与密钥配置说明」，可滚动阅读、打开 Markdown 文件或由用户点击前往官方说明。原生帮助即使聊天核心未启动也可打开。阅读教程不会自动选择供应商或改设置。

主题支持浅色、深色和跟随系统；文字大小100%/110%/125%。保存程序设置立即生效，不需要重启模型。

侧栏「专属人设」顶部可改昵称、角色形象与程序图标。分别选图后点「保存角色资料」，窗口/托盘/快捷方式立即更新；昵称和形象描述用于下一轮对话。角色形象与程序图标各自独立，可单独恢复默认。静态 PNG/JPG/WEBP 单张最多 2 MB，图标也支持 ICO。自定义保存在私有 data，备份和恢复自动包含。QQ 账号资料仍由用户在 QQ 中设置。

- Ctrl K：回到聊天输入框。
- Ctrl Q：打开退出选项。
- F5：刷新状态。
- Enter发送，Shift+Enter换行，Ctrl V可粘贴聊天图片。

## 备份与恢复

程序设置 → 创建备份：先等当前聊天完成，再确认。程序临时停止核心，复用manage.py复制完整data和配置、生成SHA256清单，然后重启核心并保持暂停。点顶部「只回复」恢复。QQ登录进程不需要退出。

列表里可以校验备份。恢复要明确选择快照并输入「恢复」确认；程序先校验，再停核心并保留当前数据到before-restore目录，然后替换data。恢复后核心**保持停止**，配置不变。先核对QQ补课/去重游标，必要时关闭QQ桥接复查，再手动启动，避免旧快照导致重复回复。详细恢复及断电处理见HANDOFF第5–7节。

窗口缓存、未发送文本草稿、系统登记与Windows启动项不属于人格数据；人格与媒体都在data，复制或快照备份即可。备份不保存环境变量值。

## 诊断与日志

「只读检查」查询本机连接、依赖、最近说话时间、磁盘余量及快照数量，不调用模型。「导出诊断」保存到.runtime/diagnostics，只含元数据，不包含聊天、记忆正文、QQ账号或环境变量值。导出后点诊断文件夹查看。

核心日志在logs/events.jsonl，窗口/托盘错误在.runtime/desktop-logs/events.jsonl，桌面运行记录会合并显示。遇到启动失败，不要删除data；先检查所选API/核心端口、依赖与日志。

## 安装、更新与移除

本版本是**本机目录安装**，桌面使用独立Python3.11、WebView2、pywebview和pystray。安装顺序为tools/install.bat、tools/install-desktop.bat；后者会创建桌面/开始菜单快捷方式并登记当前用户的Windows程序条目。安装目录移动后重新安装桌面集成并重新启用自启，更新旧路径。

本版本没有自动下载/静默安装更新，也没有发布签名EXE。维护者应先备份，再托盘「退出并停止全部」，更新受信任源码和锁定依赖，重新运行安装脚本后启动；不得用远程脚本擅自替换所选API或改安全开关。

Windows「已安装的应用 → QQ ChatBot → 卸载」会确认并移除**自启、项目快捷方式和系统登记**；程序目录、data、备份和QQ登录态保留，不会自动递归删除。要重新使用，运行tools/install-desktop.bat即可；永久删除文件由用户先保存数据后手动执行。

## 当前交付边界

桌面资源由 `src/core/desktop_assets.py` 提供，HTML/CSS/JS响应禁用缓存，样式和脚本URL携带内容指纹。更新前端后从托盘“退出界面，后台继续”再打开；无需清除WebView登录态或手动删除缓存目录。排查实际窗口样式可使用 `.venv\Scripts\pythonw.exe -m src.desktop --inspect-appearance`（先退出已有界面），它会切到能力页，生成 `.runtime/desktop-appearance.json` 和该窗口的能力页截图 `.runtime/desktop-appearance.png`，不读取聊天内容。
