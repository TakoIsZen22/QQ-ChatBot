# QQ ChatBot 1.00.01 · 自有 API 版

本机运行的个人 AI 伴侣：重长期记忆与人格养成，Windows 桌面端 + QQ 通道，数据全部存在本地。

**1.00.01 只接你自己的 OpenAI 兼容 API**，不捆绑 Magpie，也不需要本机跑 Magpie 网关。想用 Magpie 或想要内置 Magpie 教程的，请下载 [1.00.02](https://github.com/TakoIsZen22/QQ-ChatBot/releases/tag/v1.00.02)。两版的聊天、QQ、记忆与人设完全相同，只差模型接入方式。

## 首次使用需要准备什么

1. **两个 QQ 号** — 你的主人号 + 一个独立的机器人号（不能相同）。程序不注册 QQ、不索取密码，两个号需要你手动加好友并确认申请。
2. **一个自己的 OpenAI 兼容 API** — 需要服务商给你：
   - **Base URL**（通常以 `/v1` 结尾，不要填 `/chat/completions`）
   - **模型 ID**
   - **API 密钥**（自己填进 Windows 环境变量，程序只记变量名，不存密钥值）
   
   ⚠️ 只支持 OpenAI Chat Completions 兼容协议。不能只因服务名字里有"API"就认为兼容。需要工具调用（记忆、日记等）时，模型还必须支持标准 `tool_calls`；要看图则需要 `image_url`。

3. **约 3 GB 空间** — 首次向导会下载 QQ 组件。

环境变量这样设：Windows 开始菜单搜"编辑帐户的环境变量" → 用户变量 → 新建 → 变量名填 `HARNESS_API_KEY`（或你在向导里选的名字）→ 变量值填你的密钥 → 保存。**不要把密钥发给任何人，也不要写进人设或截图。** 改完环境变量要彻底退出程序再打开。

完整图文教程见仓库里的 [版本与逐步接入](EDITIONS.md) 和 [新手教程](GETTING_STARTED.md)，程序内「程序设置 → 新手教程」也能直接读。

## 功能

十二个模块：对话 / 记忆 / 角色 / 印象 / 日记 / 音乐 / 成长轨迹 / 学习 / QQ 桥接 / 设备 / 模型 / 插件。

程序只负责聊天陪伴，已移除外部 Agent、CLI 绑定和工作转交接口。维护巡检与聊天插件仍保留。

**群聊监听**（只读）：可以添加多个群查看群消息，AI 群内聊天与群记忆尚未实现。默认最多 12 个群，每窗最近 100 条，不下载附件、不转写、不上传模型。

## 安全边界

不加陌生人、不自动同意好友、不群 @全体、不碰支付银行 App；单聊限流 20 条/分；三档保命开关（一键全停 / 只回复不主动 / 群里不说话）；语音只在本机转写；密钥只存环境变量名。

`data/`、`logs/`、`.runtime/`、人设文件与账号配置都不在发布包内。

## 已知限制

- **真实 QQ 扫码与收发在新机器上仍待验收**，本版沿用此前已验证的本机主人文字闭环。新账号需要独立扫码。
- 真实群接收、QQ 媒体（语音取文件、图片上传发送）、历史补拉尚未实现。
- QQ 宿主锁定官方 QQNT 9.9.33，客户端内部接口随版本变化，需要维护者更新兼容清单。
