## 构建检查

- `tools/smoke-agent-work.py`：隔离原生工作转交页、真CLI夹具和stdio MCP回环，不执行真实工作或连接第三方Agent。
- `tools/smoke-onboarding.py`：隔离原生窗口首次使用流程；测试不会下载/登录QQ，真实组件解压另行验收。
- `tools/test.bat`：离线数据、安全、通道、桌面桥、备份恢复、资源缓存、监管与发布隔离测试。
- `tools/smoke-desktop-webview.py`：十一个页面和真实原生桥；`tools/smoke-desktop-system.py`：托盘、隐藏和恢复。
- `tools/smoke-soul-editor.py`：核心/桌面分别使用其独立环境，全部写入隔离 .runtime 测试数据，不调用模型或改正式人设。
- `tools/smoke-model-settings.py`：隔离配置和本机 API 夹具验证真实桌面的接入方式切换、未保存地址连接检查、模型清单、保存与重开；不调用外部模型或改变正式 API 配置。
- 接入教程：Magpie / 自有 API 在原生窗口内打开，固定示意图正常解码；深浅主题与窄窗口不横向溢出，正文中的 HTML 不执行；阅读教程不保存配置，桌面读取公开帮助不依赖核心或网络。
- 产品更名：新旧服务识别兼容；启动项迁移避免重复且不删除其他安装入口；角色昵称修改后产品品牌仍为 QQ ChatBot。内部协议与数据路径保持兼容。
- 自定义 API 协议夹具验证 Bearer 环境变量、文本/工具/图片请求、usage、大小上限、错误脱敏、重定向拒绝、不回退 Magpie、只读监管目标与发布配置隔离；第三方真实服务逐一待使用者验收。
- 专属人设：磁盘冲突阻止覆盖，空文件退回基础卡，data 快照恢复 soul.md 与历史；发布排除所有实际 soul.md。
- 角色资料：图片真实解码/大小/像素/静态格式校验，转 PNG 与多尺寸 ICO；拒绝路径越界和过期修改。data 快照包含资料和素材，公开源码包不携带它们。
- `--inspect-appearance`：从正式窗口生成能力页诊断，不能仅用独立浏览器截图代替。
- 发布包无 .git、data、logs、backups、.runtime、环境、local.json 或私有人设，文件集合及哈希对应 manifest。
- 干净解压后默认配置不依赖原目录，版本正确、人设无作者身份、离线测试可运行。
