# QQ ChatBot 1.00.01 / 1.00.02

同一套聊天、QQ、记忆与人设，提供两种 API 接入版本：

- **1.00.01**：仅自有 OpenAI 兼容 API，首次填写 Base URL、环境变量名与模型 ID。
- **1.00.02**：自有 API + 可选 Magpie，使用已有本机网关，不捆绑 Magpie 安装程序。
- 两版默认程序图标均换为用户提供的新图，覆盖 EXE、窗口、托盘与快捷方式；仍可自行定制。
- 修复快速 QQ 扫码窗口的启动、刷新、停止和接入设置入口，已在线或离线时隐藏旧二维码。
- 隔离启动器测试的运行目录，停止测试只操作临时宿主，避免影响本机 QQ 会话。

普通 Windows 使用者下载对应的 `qq-chatbot-版本-windows-x64.zip`，完整解压后双击 `QQ ChatBot.exe`。没有 windows-x64 后缀的 ZIP 是源码。使用者凭据、QQ 账号及登录态不包含在包内，首次运行保持全部暂停。

先阅读 [版本与逐步接入](EDITIONS.md)和[新手教程](GETTING_STARTED.md)，再在程序中设置自己的账号、人设和 API。自有 API 必须支持 Chat Completions；需要工具或图片时对应模型还需支持 tools/image_url。

QQ 宿主沿用此前已验证的本机主人文字闭环；新机器与新账号需独立扫码验收，真实群与 QQ 媒体仍待验证，历史补拉、语音取文件与图片上传发送尚未实现。完整验证边界见 ACCEPTANCE.md。
